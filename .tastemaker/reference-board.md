# Reference board (Morrow Coffee redesign)

Status: partially viewed. inspo MCP `recommend` ran for "specialty coffee roaster ecommerce" (24 sites measured). Awwwards food-drink listing fetched, but it returned names and awards only, no design detail, so no Awwwards site was studied pixel-by-pixel.

## Measured category gravity (inspo, 24 sites)
- Paper band: mid (54%). Display class: grotesk-sans (58%). Accent hue: chromatic-other (46%). Macrostructure: bento-grid dominates.
- Exemplars seen: Good Eggs (ochre + cream, full-bleed food photography), Branch (warm neutrals, serif headline), Hyper Effekt (ochre/cream, airy).

## Position taken
- AGAINST the grotesk-sans consensus: roman/italic serif display + mono utility labels.
- AGAINST bento: long-scroll narrative with an editorial index for the catalogue.
- WITH the category: warm mid-light paper, ochre/ember accent family.

## Awwwards-derived traits applied (from the listing's award winners and the site's known conventions)
- Oversized type as the hero, not a photo carousel.
- One signature interaction (the Hour Dial) instead of many small effects.
- Index/table catalogue with hover state, instead of a card grid, on the home page.
- Scroll-linked type reveal in the manifesto.

## Anti-references
- The previous build: terracotta-to-plum gradient text, gradient buttons, rounded-3xl photo, bouncing scroll indicator, blurred glow orb.
- Generic "hero, 3 cards, testimonial, CTA" rhythm.
